# Domain documentation

This is a single-context repository. Read `CONTEXT.md` before exploring or
changing code, tests, issues, or user-facing documentation. Use its canonical
terms instead of drifting to avoided synonyms.

Check `docs/adr/` for architectural decisions when that directory exists. Its
absence is not an error; decisions are recorded only when they are hard to
reverse, surprising without context, and the result of a real trade-off.

If implementation behavior conflicts with `CONTEXT.md`, surface the conflict.
Do not silently redefine the term or rewrite code around an assumed meaning.
